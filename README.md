# 멀티 프로젝트 할 일 관리

여러 프로젝트의 할 일을 한 곳에서 관리할 수 있는 웹 애플리케이션입니다.

## 주요 기능

- 📁 **프로젝트별 할 일 관리**: 여러 프로젝트를 생성하고 각각의 할 일을 관리
- 📅 **날짜 관리**: 프로젝트 기간과 할 일 마감일 설정
- ✅ **완료 추적**: 할 일 완료 체크 및 진행률 확인
- 🎨 **색상 구분**: 프로젝트별 색상으로 시각적 구분
- 💾 **로컬 저장소**: 브라우저 로컬 스토리지에 자동 저장
- ⚙️ **환경 설정**: 글씨 크기 조절 가능

## 기술 스택

- React 18
- Vite
- Tailwind CSS
- Lucide React (아이콘)

## 설치 및 실행

### 1. 의존성 설치

```bash
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 으로 접속하세요.

### 3. 프로덕션 빌드

```bash
npm run build
```

빌드된 파일은 `dist` 폴더에 생성됩니다.

### 4. 프로덕션 미리보기

```bash
npm run preview
```

## 사용 방법

1. **프로젝트 추가**: "새 프로젝트 추가" 버튼을 클릭하여 프로젝트 생성
2. **할 일 추가**: 각 프로젝트 카드에서 할 일 입력 후 Enter 또는 + 버튼 클릭
3. **날짜 설정**: 캘린더 아이콘을 클릭하여 프로젝트 기간 및 할 일 마감일 설정
4. **완료 처리**: 체크박스를 클릭하여 할 일 완료 표시
5. **프로젝트 완료**: 모든 할 일 완료 시 "프로젝트 완료로 이동" 버튼 클릭
