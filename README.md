# 멀티 프로젝트 할 일 관리자 📋

한국어 기반의 프로젝트별 할 일 관리 웹 애플리케이션

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![React](https://img.shields.io/badge/React-18.2.0-61dafb.svg)
![Test Coverage](https://img.shields.io/badge/coverage-100%25-brightgreen.svg)

## 🎯 앱 소개

여러 프로젝트를 동시에 관리하고, 각 프로젝트별로 할 일을 추가하고 추적할 수 있는 할 일 관리 웹 앱입니다.

### 화면 구성
```
┌────────────────────────────────────────────┐
│  오늘의 할 일                    ⚙️ 설정  │
│  2026년 1월 12일 일요일                    │
│  진행률: 50% (5/10)                       │
├────────────────────────────────────────────┤
│  [+ 새 프로젝트 추가]                      │
├──────────────────┬─────────────────────────┤
│ 📁 프로젝트 A    │ 📁 프로젝트 B          │
│ (파랑색)         │ (보라색)               │
│ 12/1 ~ 12/31    │ 1/1 ~ 1/15            │
│                 │                        │
│ ☐ 회의 자료 준비 │ ☐ 디자인 시안 검토     │
│   📅 12/25      │   📅 1/14             │
│ ☐ 피드백 반영    │ ☐ 개발 일정 조율       │
│   📅 12/30      │   📅 1/15             │
│                 │                        │
│ [+ 새 할 일]    │ [+ 새 할 일]          │
└──────────────────┴─────────────────────────┘
```

## ✨ 주요 기능

### 📁 프로젝트 관리
- ✅ 여러 프로젝트를 한 화면에서 관리
- 🎨 프로젝트별 색상 지정 (8가지 색상)
- 📅 프로젝트 시작일/종료일 설정
- ✏️ 프로젝트명 즉시 수정
- 🗑️ 프로젝트 삭제
- ✅ 완료된 프로젝트는 별도 섹션으로 이동

### 📋 할 일 관리
- ➕ 각 프로젝트에 할 일 추가
- ☑️ 체크박스로 완료/미완료 토글
- 📆 마감일 설정
- ⚠️ 마감일 지난 할 일은 빨간색 표시
- 🗑️ 할 일 삭제
- 📂 완료된 할 일 드롭다운으로 숨기기

### 🎯 진행률 & 정렬
- 📊 전체 할 일 완료율 실시간 표시
- 🔄 마감일 빠른 순으로 자동 정렬
- 🎉 모든 할 일 완료 시 축하 메시지

### ⚙️ 사용자 설정
- 🔤 글씨 크기 조절 (작게/보통/크게)
- 💾 모든 데이터 자동 저장 (로컬스토리지)
- 🔄 새로고침해도 데이터 유지

## 🚀 실행 방법

### 1️⃣ 개발 서버 실행
```bash
npm install          # 의존성 설치 (처음 한 번만)
npm run dev          # 개발 서버 시작
```

서버 시작 후 접속:
- **로컬**: http://localhost:3000/
- **네트워크**: http://[IP주소]:3000/

### 2️⃣ 프로덕션 빌드
```bash
npm run build        # dist/ 폴더에 빌드
npm run preview      # 빌드 결과 미리보기
```

### 3️⃣ 테스트 실행
```bash
npm test                # 테스트 실행 (61개)
npm run test:watch      # Watch 모드
npm run test:coverage   # 커버리지 확인 (100%)
```

## 🔧 문제 해결

### 서버가 실행되지 않아요
```bash
# 포트가 사용 중인지 확인
lsof -i :3000

# 다른 포트로 실행
npm run dev -- --port 3001
```

### 브라우저에서 접속이 안돼요
```bash
# 모든 네트워크에서 접속 허용
npm run dev -- --host 0.0.0.0
```

### 데이터가 저장되지 않아요
- 브라우저의 로컬스토리지가 활성화되어 있는지 확인
- 시크릿 모드에서는 데이터가 저장되지 않을 수 있습니다
