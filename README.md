# ProTodo 스케줄러

프로젝트, 업무, 루틴, To-do list를 한 곳에서 관리하는 스케줄러

## 📋 주요 기능

### 1. **캘린더 뷰**
- **주간 뷰**: 일주일 단위로 일정 확인 (기본 대시보드)
- **월간 뷰**: 한 달 전체 일정 한눈에 보기
- 날짜 네비게이션으로 자유롭게 이동

### 2. **프로젝트 일정 관리**
- 프로젝트 시작일/종료일 설정
- Task 리스트 입력 (엑셀 복사 붙여넣기 지원)
- **자동 일정 배정**: 주말/공휴일 제외하고 작업 가능 일수에 자동 배치
- **P-Task (Project Task)**: 프로젝트 순서 유지, 뒤로만 이동 가능
- 프로젝트별 색상 구분

### 3. **자유 일정 관리**
- **F-Task (Free Task)**: 개별적으로 입력/수정/삭제 가능
- 각 날짜 Cell에서 바로 할일 추가
- 드래그 앤 드롭으로 자유롭게 이동

### 4. **Task 기능**
- ✅ 체크박스: 완료 표시
- ⏰ 시간 설정: 특정 시간 지정 가능
- 🗑️ 삭제: Task 제거
- 드래그 앤 드롭으로 날짜 간 이동

### 5. **오늘의 할일 대시보드**
- 오늘 예정된 모든 Task 한눈에 확인
- 진행률 표시
- 완료 시 축하 메시지

## 🏗️ 프로젝트 구조

### 데이터 구조
- **Cell**: 하루 단위
- **P-Task**: 프로젝트 Task (순서 유지, 뒤로만 이동)
- **F-Task**: 자유 Task (자유롭게 이동)
- **Routine**: 반복 일정 (일/주/월/년간)

### 계층 구조
```
한달 스케줄러 > 주간 스케줄러 > 하루(Cell) > 할일(Task)
```

## 🎯 사용 방법

### 1. 프로젝트 일정 잡기
1. "프로젝트 일정" 버튼 클릭
2. 프로젝트 이름 입력
3. 시작일, 종료일 설정
4. Task 리스트 작성 (한 줄에 하나씩 또는 엑셀 복사 붙여넣기)
5. 완료 버튼 클릭
6. 자동으로 작업 가능 일수에 Task 배정

### 2. 하루 일정 잡기
1. 캘린더에서 날짜 숫자 클릭
2. 할일 입력 후 Enter
3. 추가 할일 계속 입력 가능
4. Cell 외부 클릭하여 완료

### 3. Task 관리
- **완료 표시**: 체크박스 클릭
- **시간 설정**: 시계 아이콘 클릭
- **삭제**: 휴지통 아이콘 클릭
- **이동**: Task를 드래그하여 다른 날짜로 이동

### 4. 뷰 전환
- **주간 뷰**: 일주일 단위로 상세하게 보기
- **월간 뷰**: 한 달 전체를 한눈에 보기

## 📝 특징

### P-Task vs F-Task
- **P-Task (프로젝트 Task)**
  - 프로젝트에 속한 Task
  - 순서가 중요하여 뒤로만 이동 가능
  - 프로젝트 색상으로 구분
  - 자동 재배정 기능

- **F-Task (자유 Task)**
  - 개별적으로 관리되는 Task
  - 어디든 자유롭게 이동 가능
  - 빠른 입력 및 수정

### 자동 일정 배정
- 시작일과 종료일 사이의 작업 가능 일수 계산
- 주말(토, 일) 자동 제외
- 공휴일 제외 (설정 가능)
- Task 수에 맞춰 자동 배치
